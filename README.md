# Burooj Consulting

Website for **Burooj Management and Legal Consulting Firm**, a Jeddah-based advisory firm supporting Saudi and international companies with management consulting, legal coordination, feasibility studies, SIDF submissions, and investor soft-landing services.

## Stack

- React + Vite + TypeScript
- Plain CSS
- lucide-react icons

## Run locally

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Notes

- The site is currently English-only, with structure suitable for Arabic localization later.
- Formal legal representation is described as coordinated through the partnering licensed law firm, **Muhammad Gamal Rushdi Law Firm**.
